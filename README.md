# WhatsApp Clone Backend

Backend for a real-time messaging system built with FastAPI and PostgreSQL.

---

## Features

- User authentication (JWT + Refresh Tokens)
- Secure password hashing
- Real-time messaging (WebSockets - upcoming)
- Conversation system (upcoming)
- Message delivery tracking (upcoming)

---

## Tech Stack

- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- JWT Authentication
